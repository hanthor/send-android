# Implementation status

Send is an original Kotlin/Compose Matrix Android client with a conversation-first interface inspired by Android messaging patterns. It does not contain code or assets decompiled from Google Messages.

## Implemented paths

- Rust Matrix SDK `26.09.28` Android platform verifier bootstrapping before client creation; password, QR scan, SSO browser redirect, persisted session restoration, and an encrypted local SDK store whose key is wrapped by Android Keystore.
- SDK room-list updates show joined encrypted rooms; newly created encrypted DMs are inserted immediately from the successful server response. Unencrypted rooms are hidden and rejected by open/send/reaction operations.
- Encrypted text timeline send/receive, backward pagination, reactions, and room-keyed composer drafts that survive activity/process restoration. Conversation bubbles show localized event times, `Sent` for own messages, and quick emoji reactions from a long press.
- Instrumentation covers login validation, local Synapse sign-in, encrypted direct-room creation, encrypted message send and local timeline rendering, new-chat validation, legal notices, and reaction selection. GitHub Actions runs assemble, unit tests, lint, and Android-emulator instrumentation; successful runs upload full-resolution screenshots and the debug APK.

## Known implementation limits

- Element Call `0.1.0-rc.7` exposes no host-facing incoming-call invitation/event flow, accept/decline API, or supported inbound entry point. Incoming call alerts and accept/decline are not implemented; no fake inbound controls are shown.
- Encrypted 1:1 room creation from a Matrix user ID is implemented. Push notifications, Android Auto, widgets, dictation, text-to-speech, and AI features remain roadmap items in `ANDROID_INTEGRATIONS.md`.
- CI provisions two Synapse demo accounts, but instrumentation sends as Alice only; Bob's independent device decryption/delivery, pre-existing remote room-list population, encryption recovery, and live MatrixRTC calls are not verified. The CI emulator cannot resolve `matrix.reilly.asia`, so remote SSO/production login is also unverified.
- Element Call is a release candidate; upstream APIs may change. This repository uses its documented minimum Rust SDK version `26.09.26`; the pinned stable SDK `26.09.28` meets that floor, with build/runtime compatibility still to verify.

## Build and delivery

- Public repository: https://github.com/hanthor/send-android
- GitHub Actions provisions Gradle `9.6.0` through the committed Gradle wrapper and Android API 37; builds/tests/lint run in GitHub CI, not locally, per request.
- CI uploads the debug APK (`Send-debug-APK`), reports (`Send-Android-Test-Results`), and full-resolution fixture/live Synapse screenshots (`Send-UI-Screenshots`) for 30 days. The checked-in walkthrough PNGs are generated by that workflow; live screenshots show a locally created encrypted conversation and an SDK-sent message.
- Latest verification: [GitHub Actions run 38440351056](https://github.com/hanthor/send-android/actions/runs/38440351056) passed assemble, unit tests, lint, local Synapse demo-user setup, Android emulator integration, and screenshot capture (8 tests, 0 failures).
